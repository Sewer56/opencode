Apply a multi-file patch. Envelope: `*** Begin Patch` / `*** End Patch`.
Operations: `*** Add File: <path>`, `*** Delete File: <path>`, `*** Update File: <path>` (with `*** Move to: <new>` for renames).
Within Update sections: `@@ context_line` marks edit location. `+` prefix for new lines, `-` for removed, plain for context.
